# Sample input files

Drop raw outbound list files here (CSV, XLSX, TSV, exports from ZoomInfo, Clay,
HubSpot, lemlist, conference lists, etc.) exactly as you received them. Don't
pre-clean them — messy inputs are what the cleaning scripts get tested against.

Files in this folder are treated as read-only test inputs; the scripts will
write their cleaned output somewhere else.

Heads-up: these lists usually contain personal contact data (names, emails,
phone numbers). Anything committed here is visible to everyone who can read
this repository.
